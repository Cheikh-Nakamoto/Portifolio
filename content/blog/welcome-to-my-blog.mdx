Hi, I'm Cheikh Mounirou Coly Diouf, a fullstack engineer based in Dakar, Senegal. I write Go, Java, Rust and TypeScript, and I like building complete products, from the database schema to the Docker container that runs them in production.

This blog is where I'll write down what I learn along the way.

## How I got here

I've always wanted to understand what happens behind the screen. How does an app know who I am? How does a page load in a fraction of a second? How can millions of people use the same service at the same time?

In January 2023 I joined **01 Talent Senegal (Zone 01 Dakar)**. There were no lectures there. We learned through projects, peers, code reviews and long debugging sessions. Over three years I built more than 30 projects, including:

- **Kay-Point**, a multi-tenant SaaS concept with 23k+ lines of Go, a React 19 dashboard and a Flutter app.
- **TradeFlowSN**, a container logistics platform running in production, with 233 automated tests and a Jenkins CI/CD pipeline.
- **Generateur-d'architecture**, a Rust desktop tool that scaffolds projects with the help of an LLM.

## Why a blog?

Building things teaches me a lot, but I forget half of it if I don't write it down. Writing forces me to really understand a topic: if I can't explain it simply, I don't know it well enough yet.

<Callout type="tip">
Learning in public means sharing notes while you're still learning, not only after you've become an expert. Mistakes included.
</Callout>

## What to expect

I'll write about the things I run into while building software:

- **Backend & systems**: Go, Rust, Java and Spring Boot, concurrency, databases.
- **Architecture**: Clean Architecture, multi-tenant SaaS, microservices, and the tradeoffs between them.
- **DevOps**: Docker, CI/CD pipelines, monitoring with Prometheus and Grafana.
- **Web3**: what I learn exploring Hedera and the crypto ecosystem.
